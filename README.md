## 关于本项目

OpenHarness Go 是一个开源的 AI 编码助手项目，基于云雀科技的 Eino ReAct 框架构建。该项目旨在解决开发者在 AI 编码辅助过程中的核心痛点，提供智能代码生成、文件操作、技能学习等能力。
